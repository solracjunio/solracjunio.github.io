O computador e as ferramentas que eu uso para programar e desenvolver jogos.

## Hardware

| Peça | Modelo |
|------|--------|
| Processador | AMD Ryzen 5 3600 (6 núcleos, 12 threads) |
| Placa-mãe | ASRock A320M-HDV R4.0 |
| Memória | 32 GB DDR4 (2 × 16 GB, 2400 MHz) |
| Placa de vídeo | NVIDIA GeForce RTX 2060 |
| Armazenamento | SSD NVMe Kingston NV1 500 GB + SSD SATA Crucial BX500 500 GB |
| Monitor principal | AOC 24G2E1, Full HD (1920 × 1080), na horizontal |
| Monitor secundário | LG Full HD (1080 × 1920), na vertical |

## Sistema

- **Windows 11 Pro**
- **WSL 2** com **Ubuntu 24.04 LTS**: os projetos web rodam inteiros no Linux.

## Desenvolvimento web

- **[Devbox](https://www.jetify.com/devbox):** fixa as versões de **Node.js 26** e **pnpm 12** por projeto, para todo mundo usar as mesmas.
- **Docker:** bancos de dados e serviços locais, como o PostgreSQL.
- **Git** e **GitHub**, com CI no GitHub Actions.
- **VS Code** como editor.
- **Claude Code** como assistente de programação.

## Desenvolvimento de jogos

- **Unity 6** (6000.3) com **C#**.

## Organização

- **Obsidian** para notas e planejamento dos projetos.
